# WESSI — AI-Powered Waste Segregation

WESSI is an AI-powered waste classification and segregation system designed to support more efficient and sustainable waste management.

## Project Vision

WESSI is being developed with the goal of supporting waste management and segregation facilities through automated identification and classification of waste.

The current system focuses on AI-based waste detection and classification. Future development aims to scale the solution for integration with advanced robotic infrastructure at waste management plants, enabling automated sorting of different waste materials.

## Problem

Improper segregation of waste makes recycling and waste processing more difficult and can increase the amount of waste sent to landfills. Manual sorting can also be time-consuming and difficult to scale.

## Proposed Solution

WESSI uses computer vision and AI-based object detection to identify different categories of waste from images or camera input. The detected waste can then be classified into appropriate categories to support the segregation process.

WESSI is aligned with **UN Sustainable Development Goal 12 — Responsible Consumption and Production**, particularly the responsible management and reduction of waste.
